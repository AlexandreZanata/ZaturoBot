Descrição completa reproduzida do anúncio

O Kingston NV3 de 500 GB é uma unidade SSD interna pensada para quem busca mais agilidade no computador sem ocupar espaço excessivo. No formato 2280, ele usa conexão NVMe sobre PCI Express 4.0 x4 para favorecer respostas rápidas no uso diário.

Com memória 3D NAND, o modelo entrega uma experiência equilibrada para abrir programas, navegar e lidar com arquivos com menos espera. A linha NV3 também atende bem quem procura desempenho para estudo, trabalho ou jogos.

Seu corpo compacto mede 2,2 cm de largura, 0,23 cm de altura e pesa cerca de 7 g. Isso ajuda na organização interna do equipamento e torna a escolha prática para sistemas que aceitam o padrão 2280.

O modelo SNV3S/500G opera em uma faixa de temperatura de 0 °C a 70 °C e tem suporte listado para Chrome OS, Linux, macOS e Windows.
