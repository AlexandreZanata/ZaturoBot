ZaturoBot includes a small subset as local SVG resources for its native Linux client.
The upstream SVG files are unmodified: original fills, viewBox and path geometry are
preserved. Application file names match the corresponding Android resource identifiers.
Slint controls rendered size and state-specific color through its colorize property.
These generic interface symbols are separate from the owner's ZaturoBot brand mark;
the smart_display symbol is not a Google or YouTube brand logo or an affiliation claim.

The exact upstream revision, per-icon URLs and SHA-256 hashes are in provenance.json.
SHA256SUMS verifies the original SVG files and full license. These assets require no
icon font, runtime network access or additional Material library.
