# Semantic computer and service adapters

Read the root instructions and docs/COMPUTER_USE.md. This crate owns fixed bounded
subprocess transport to the reviewed Linux/Playwright MCP, BitLupa and social helpers.
Core owns action/lease/observation contracts; services own parent/approval policy; db owns
Zaturo state. No planning, SQL, provider keys, arbitrary shell, argv or HTTP origin here.

`ComputerConfig` selects private local profiles and reviewed helper paths, never a model.
`execute` independently enforces leases, exact owner-approved plan digests, fixed script
mapping, environment filtering, output bounds and owned process-group cleanup. Unknown
input/publication outcomes stop for reconciliation. API acceptance is not publication.
Price output uses observed exact variants/BRL/times/URLs; do not invent collector data.

`capture` is separate zeroizing RAM-only PNG transport from the locally fixed granted
window. No pixels in ordinary observations, models, files, SQL or logs. Never fall back
to another window, normal browser, shell or unregistered device to make an action succeed.
Native helpers enforce fresh target/snapshot, local app/origin grants and emergency STOP.
Same-user application restrictions are not an OS/network sandbox.

Tests use fake helper processes, synthetic records/PNG and local HTTP only. Preserve
cancellation, uncertainty, secret redaction, exact draft binding and no-fabrication checks.

`capture_wayland` is a separate explicit local portal grant, never a fallback from X11. The reviewed helper binds one nonpersistent window source and remote FD, with bounded appsink PNG output only to worker RAM. Native portal consent is mandatory.
